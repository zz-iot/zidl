# zidl-bindings

Binding support: allocator adapters, owned values, entity boxes, retirement
observers and authoring helpers. Import `zidl-bindings` (`zidl_bindings` alias).
It depends on `zidl-cdr` and reexports that same module as `zidl_cdr`.
Run `zig build test` for its tests.

See [package placement](../../docs/design/native-cdr-package-slice.md).
